# ImageApp

ImageApp — проект на C# Windows Forms для экспериментов с собственным lossless-форматом изображений и проверкой целостности данных.

Приложение умеет читать обычные изображения, преобразовывать их во внутреннее представление пикселей, сохранять в собственный бинарный формат, открывать сохранённые файлы и строить графики для экспериментов со сжатием и передачей данных.

English version: [README.md](README.md)

## Возможности

- Интерфейс Windows Forms для сохранения и открытия изображений.
- Собственное палитровое кодирование изображений:
  - список уникальных RGB-цветов сохраняется один раз;
  - каждый пиксель записывается как индекс в этой палитре;
  - на индекс выделяется минимальное число бит, достаточное для размера палитры.
- Улучшенный кодировщик с RLE-сжатием последовательных пикселей одного цвета.
- Графики сравнения PNG, стандартного кодировщика и улучшенного кодировщика.
- Симуляция ошибок передачи через случайное инвертирование битов.
- Эксперименты с проверкой целостности:
  - блоки с битом чётности;
  - MD5-хэши для блоков фиксированного размера.

## Требования

- Windows с .NET Framework 4.7.2 или новее.
- Visual Studio с компонентами для разработки .NET desktop-приложений.

Это классическое Windows Forms-приложение, поэтому оно рассчитано на сборку и запуск в Windows.

## Как запустить

1. Открыть `ВычМач/ImageApp/ImageApp.sln` в Visual Studio.
2. Собрать solution.
3. Запустить проект `ImageApp`.

## Основные действия в приложении

- **Save Image** — открыть изображение и сохранить его в собственном бинарном формате.
- **See Image** — открыть ранее сохранённый `.bin` файл и показать декодированное изображение.
- **Show graph** — сравнить собственные кодировщики с PNG на тестовом наборе изображений.
- **Show graph 2** — запустить эксперименты с проверкой целостности и показать график.

## Кратко о формате

Базовый формат изображения хранит:

1. 24 бита — количество уникальных цветов.
2. 16 бит — ширина изображения.
3. 16 бит — высота изображения.
4. По 24 бита на цвет — RGB-значения палитры.
5. Данные пикселей — каждый пиксель хранится как индекс цвета в палитре, для индекса используется `ceil(log2(количество цветов))` бит.

Улучшенный формат сохраняет тот же заголовок и палитру, но записывает повторяющиеся подряд пиксели парами `(длина серии, индекс цвета)`. Длина серии хранится в 8 битах.

## Эксперименты с целостностью

Вторая часть проекта проверяет, как битовые последовательности переживают передачу со случайными ошибками.

- Метод с битом чётности добавляет один проверочный бит на каждые 8 бит данных.
- Метод с MD5 делит данные на блоки по 952 бита и добавляет к каждому блоку 128-битный MD5-хэш.

Оба метода тестируются через многократное случайное инвертирование битов с заданной вероятностью и сравнение полученных данных с исходными.

## Заметки

В текущем коде часть файловых диалогов использует абсолютные Windows-пути с исходного компьютера разработки. При запуске на другом ПК эти пути может понадобиться обновить или выбирать файлы вручную через диалог, где это возможно.

`.gitignore` игнорирует артефакты сборки и локальные файлы Visual Studio, но старые сгенерированные файлы могут оставаться в истории репозитория.
